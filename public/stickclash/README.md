# STICK CLASH

Instant couch-multiplayer stickman fights on ONE device: no installs, accounts, downloads or internet.

* Play: double-click `index.html`, or serve this folder with `npx serve .` / `python -m http.server 8000`.
* Deploy: put this folder's contents at the root of a GitHub repo → Settings → Pages → Deploy from a branch → main / root.
* Full docs (modes, controls, architecture, demo script): see the README at the root of the project repository.

MIT licensed. All art is drawn in code and all sounds are synthesised with WebAudio.
